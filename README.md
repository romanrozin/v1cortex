# v1cortex

Fork of [Training-data-driven-V1-model](https://github.com/ifgovh/Training-data-driven-V1-model) adapted for training the [Billeh et al.](https://doi.org/10.1016/j.neuron.2020.01.040) V1 model on MNIST. The code for [huggingface.co/romanrozin/v1cortex](https://huggingface.co/romanrozin/v1cortex) is tagged as `hf`. See the original [README](https://github.com/ifgovh/Training-data-driven-V1-model/blob/main/README.md) for more information.
